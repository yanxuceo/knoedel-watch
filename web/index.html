How it works安装步骤

  1. Choose your watch above. A firmware for the other board does not start on yours, but harms nothing: install again with the right one. 在上面选择你的手表。装错了另一款的固件，手表不会启动，但也不会损坏：选对后重新安装即可。
  2. Use Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). 在电脑上用 Chrome 或 Edge 浏览器（Windows、macOS、Linux 或 ChromeOS 均可）。
  3. Connect the watch with a USB-C cable that carries data (some cables only charge). 用一根能传数据的 USB-C 线连接手表（有些线只能充电）。
  4. Press Install, choose the watch in the list (it shows as a USB serial or USB JTAG device) and confirm. 点 安装，在弹出的列表里选中手表（显示为 USB 串口或 USB JTAG 设备），然后点 Connect（连接）。之后的安装窗口是英文的，下面会说明要点哪些按钮。
  5. You are asked whether to erase the watch. First install: yes. Updating later: no keeps your progress and settings. 点 Install Knödel Watch（安装），它会问是否清空手表（Erase device）。第一次安装：勾选它。以后更新：不勾选，练习进度和设置都会保留。然后点 Next（下一步）和 Install（安装）。
  6. Wait until it says it is done (about two minutes). The watch restarts in English; Settings → Language switches to Chinese, Settings → Time sets the clock. 等到显示 Installation complete!（安装完成，大约两分钟）。手表会重启并显示英文界面；Settings → Language 可以切换成中文，设置 → 时间 可以设置时钟。

If something goes wrong遇到问题

The watch is not in the list列表里找不到手表

Try another cable or another USB port, and make sure no other program (a serial monitor, Arduino, another browser tab) is using the watch. On Linux your user may need to be in the dialout group.

换一根线或换一个 USB 口，并确认没有其他程序（串口监视器、Arduino、另一个浏览器标签页）正在占用手表。在 Linux 上，你的用户可能需要加入 dialout 组。

Installing stopped halfway安装到一半中断了

Just install again. A content pack that was only partly written is detected by the watch, which then shows "No content" instead of starting.

重新安装一次就好。只写了一半的内容包会被手表识别出来，手表会显示 "No content"，而不会带着坏数据启动。

I prefer the command line我更习惯用命令行

Download the image for your watch from the project's releases, knoedel-watch-{{VERSION}}-m5_stopwatch-full.bin or knoedel-watch-{{VERSION}}-waveshare_175c-full.bin, and run python3 -m esptool --chip esp32s3 write-flash 0x0 <file> (pip install esptool). This is a fresh install: it erases progress and settings.

从项目的 Releases 下载你手表对应的镜像：knoedel-watch-{{VERSION}}-m5_stopwatch-full.bin 或 knoedel-watch-{{VERSION}}-waveshare_175c-full.bin，然后运行 python3 -m esptool --chip esp32s3 write-flash 0x0 <文件>（先 pip install esptool）。这相当于全新安装，会清空练习进度和设置。

The cards were written by an AI and have not been proofread by a native speaker yet; the German audio is synthetic speech. Found a mistake? Please open an issue on the project page. 卡片内容由 AI 编写，尚未经母语者校对；德语配音是合成语音。发现错误？欢迎在项目页面提 issue。
